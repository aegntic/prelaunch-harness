Prelaunch harness

A scan receipt is not a certification.

This mark does not say verified, checked, approved, compliant, or safe to launch. It records that a file set was submitted to a signal scanner. The operator remains responsible for what ships.

Agents call POST /scan with { subject, files: [{ path, content }] }. The response is a receipt: tree hash, family table, findings. Embed the mark only beside that receipt.

Price, when PAY_TO is set: 0.02 USDC on Base. Unset, the scan stays open so the receipt format can be tested. Payment does not buy a legal conclusion.
